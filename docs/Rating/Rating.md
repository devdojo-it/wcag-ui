# Rating

The **Rating** component is a reusable, accessible UI element.

## Usage

```html
<element is="wcag-rating"></element>
```

## WCAG Accessibility

- Uses semantic HTML elements.
- Supports ARIA attributes where appropriate.
- Keyboard navigation enabled.
- Focus management compliant with WCAG 2.1.
