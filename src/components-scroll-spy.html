ScrollSpy

Il componente ScrollSpy evidenzia automaticamente la sezione correntemente visibile nella navigazione. È ideale per pagine lunghe con sommari laterali, basandosi sugli anchor link per aggiornare lo stato attivo durante lo scroll.

Come si usa:
  • Usa ScrollSpy per pagine di documentazione o articoli lunghi con un sommario di navigazione laterale
  • Abbina lo stato attivo a un indicatore visivo non basato solo sul colore (bordo, grassetto, icona)
Come non si usa:
  • Non spostare il focus automaticamente durante lo scroll, lascia sempre il controllo all'utente
  • Evita di usarlo per strutture di navigazione brevi dove l'utente può già vedere tutti i contenuti

Getting started

Quick Start

Installa il pacchetto tramite pnpm e importa il componente nel tuo progetto per iniziare subito a costruire interfacce accessibili.

Una volta importato, puoi utilizzare il tag section[is="wcag-scroll-spy"] puntando al contenitore target tramite l'attributo target.

Install manually

Scarica i file compilati (.min.js e .min.css) e includili direttamente nel tuo HTML senza dipendenze aggiuntive.

Questo approccio è ideale per prototipi rapidi o ambienti senza un bundler configurato.

Usage from CDN

Puoi includere wcagUI direttamente da CDN usando un tag <script type="module"> per caricare i componenti senza nessuna configurazione locale.

Consulta la sezione Integrations per tutti i metodi di installazione supportati e le varianti di importazione disponibili.
